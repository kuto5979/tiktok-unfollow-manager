# TikTok Unfollow Manager Website

Files:
- index.html — main website / Web/Desktop URL
- privacy.html — Privacy Policy URL
- terms.html — Terms of Service URL
- style.css — shared styling

Upload all four files to the same folder on a static website host.

Then use:
Web/Desktop URL: https://YOUR-DOMAIN/
Privacy Policy URL: https://YOUR-DOMAIN/privacy.html
Terms of Service URL: https://YOUR-DOMAIN/terms.html

Replace YOUR-DOMAIN with the actual domain/host URL.

Important: these pages describe the current intended app behavior. Update the Privacy Policy and Terms if the app's actual data handling or features change.
